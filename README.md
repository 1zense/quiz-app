# QuizMaster — Платформа викторин с геймификацией

Django-приложение для проведения викторин с системой уровней, достижений и таблицей лидеров.

**[PDF-файл с курсовым проектом](kp/МИСПИСиТ_КП_Конюхов_Д-Э311.pdf)**

## Стек

**Backend:** Django 4.2\
**База данных:** PostgreSQL\
**Frontend:** HTML/CSS/JS + встроенные шаблоны Django

## Возможности

**Система авторизации** — регистрация, вход, профиль, аватар\
**Викторины** — категории, уровни сложности, таймер на вопрос\
**Таблица лидеров**\
**Разбор результатов** после каждой викторины\
**Геймификация:**
  - Очки за правильные ответы
  - Бонусы за быстрые ответы и серии (стрики)
  - Уровни пользователя (7 уровней: Новичок -> Легенда)
  - Достижения с наградами
  - Ежедневные серии

## Быстрый старт

### 1. Локальный запуск

```bash
cd quiz_app

# Зависимости
pip install -r requirements.txt

# Создать базу PostgreSQL
createdb quizdb
createuser quizuser
# или через psql:
# CREATE DATABASE quizdb;
# CREATE USER quizuser WITH PASSWORD 'quizpass';
# GRANT ALL PRIVILEGES ON DATABASE quizdb TO quizuser;

# Настройка переменных окружения
cp .env.example .env

# Применить миграции
python manage.py migrate

# Заполнить демо-данными
python seed_data.py

# Запустить сервер
python manage.py runserver
```

Открыть http://127.0.0.1:8000

### 2. Запуск через Docker Compose

```bash
docker-compose watch
# или
# docker-compose up --build

# В другом терминале для заполнения демо-данными
docker-compose exec web python seed_data.py
```

## Геймификация

| Действие | Очки |
|----------|------|
| Правильный ответ | +10 |
| Быстрый ответ (<5 сек) | +3 |
| Серия каждые 3 ответа | +5 |
| Получение достижения | +50–250 |
